# GradeSense - ADN (Internal Marks Transparency & Performance Dashboard)

## Overview
This repository contains the design, API contract documents, CSV templates and deployment guides for the ADN component of GradeSense: the department-level platform where faculty upload internal marks and students view analytics.

## Repo structure
- `docs/` - API specs, CSV templates, requirements
- `design/` - wireframes and UI guidelines
- `backend/` - backend specs (ASP.NET Core)
- `frontend/` - frontend specs (React + Tailwind)
- `tests/` - test plans
- `deploy/` - deployment and CI/CD docs

## Branching model
- `main` - production-ready
- `develop` - integration branch for weekly merges
- `feature/*` - feature branches

## Milestones
Week1..Week7 milestones defined in the GitHub project board.

## Quick start (docs only)
See `docs/requirements.md` and `docs/api-spec.md` for details.
